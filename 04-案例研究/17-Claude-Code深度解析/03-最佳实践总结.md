## 20.11 安全实践

### 20.11.1 沙箱执行

**原则**：代码执行在隔离环境中进行。

**实现**：
```python
class Sandbox:
    def __init__(self):
        self.allowed_paths = ["./workspace"]
        self.forbidden_paths = ["/", "/home", "/etc"]
    
    def execute(self, command):
        # 检查路径权限
        if self.is_forbidden(command):
            raise PermissionError("Access denied")
        
        # 在沙箱中执行
        return self.run_in_sandbox(command)
    
    def is_forbidden(self, command):
        for path in self.forbidden_paths:
            if path in command:
                return True
        return False
```

### 20.11.2 权限控制

| 操作 | 权限级别 | 说明 |
|------|----------|------|
| 读取文件 | 低 | 允许读取工作目录 |
| 写入文件 | 中 | 仅允许工作目录 |
| 执行命令 | 高 | 需要明确授权 |
| 网络访问 | 高 | 需要明确授权 |

## 20.12 可靠实践

### 20.12.1 状态快照

```python
class StateManager:
    def __init__(self):
        self.snapshots = []
    
    def save_snapshot(self, state):
        snapshot = {
            "timestamp": time.time(),
            "state": state
        }
        self.snapshots.append(snapshot)
    
    def restore(self, snapshot_id):
        return self.snapshots[snapshot_id]
```

### 20.12.2 熔断器

```python
class CircuitBreaker:
    def __init__(self, threshold=5, timeout=60):
        self.threshold = threshold
        self.timeout = timeout
        self.failures = 0
        self.last_failure = 0
    
    def call(self, func):
        if self.is_open():
            raise CircuitOpenError()
        
        try:
            result = func()
            self.failures = 0
            return result
        except Exception:
            self.failures += 1
            self.last_failure = time.time()
            raise
```

### 20.13.2 上下文管理

```python
class ContextManager:
    def __init__(self, max_tokens=8000):
        self.max_tokens = max_tokens
        self.history = []
    
    def add_message(self, message):
        self.history.append(message)
        self.trim()
    
    def trim(self):
        # 保持上下文在限制内
        while self.get_total_tokens() > self.max_tokens:
            self.history.pop(0)
```
