## 20.6 理论要点：可靠性的三大支柱

### 20.6.1 三大支柱

| 支柱 | 说明 | Claude Code 实现 |
|------|------|------------------|
| **容错** | 系统部分失败时仍能运行 | 状态快照、插件熔断 |
| **恢复** | 故障后能快速恢复 | 断点续跑、回滚机制 |
| **可观测** | 能看见系统内部状态 | 详细日志、trace 可视化 |

### 20.6.2 与豆包的对比

| 维度 | Claude Code | 豆包 |
|------|-------------|------|
| **容错** | 状态快照 + 插件熔断 | 重试 + 降级 |
| **恢复** | 断点续跑 + Git 集成 | 状态文件 + 重试 |
| **可观测** | Trace 可视化面板 | 日志 + 指标 |
| **部署** | 本地 + 云端 | 云端为主 |
| **适用场景** | 软件开发 | 通用办公 |

## 20.7 实战案例：可靠性机制实现

### 20.7.1 状态快照

```python
class StateSnapshot:
    def __init__(self):
        self.snapshots = []
    
    def create_snapshot(self, state):
        """创建状态快照"""
        snapshot = {
            "timestamp": time.time(),
            "state": state,
            "context": get_current_context()
        }
        self.snapshots.append(snapshot)
        return snapshot
    
    def restore(self, snapshot_id):
        """恢复到指定快照"""
        snapshot = self.get_snapshot(snapshot_id)
        restore_state(snapshot["state"])
        restore_context(snapshot["context"])
```

### 20.7.2 插件熔断

```python
class PluginCircuitBreaker:
    def __init__(self, failure_threshold=5, reset_timeout=60):
        self.failure_threshold = failure_threshold
        self.reset_timeout = reset_timeout
        self.failure_count = {}
        self.last_failure_time = {}
    
    def call(self, plugin_name, func):
        """调用插件"""
        if self.is_open(plugin_name):
            raise CircuitOpenError(f"Plugin {plugin_name} is open")
        
        try:
            result = func()
            self.reset(plugin_name)
            return result
        except Exception as e:
            self.record_failure(plugin_name)
            raise
    
    def is_open(self, plugin_name):
        """检查熔断器是否打开"""
        if plugin_name not in self.failure_count:
            return False
        
        if self.failure_count[plugin_name] >= self.failure_threshold:
            elapsed = time.time() - self.last_failure_time[plugin_name]
            if elapsed < self.reset_timeout:
                return True
            else:
                self.reset(plugin_name)
                return False
        return False
```
