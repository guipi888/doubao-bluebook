## 22.10 核心模式详解

### 22.10.1 Pipeline（管道）模式

**适用场景**：数据流处理

```
Input → Transform1 → Transform2 → Transform3 → Output
```

**代码示例**：
```python
class Pipeline:
    def __init__(self):
        self.steps = []
    
    def add_step(self, func):
        self.steps.append(func)
    
    def execute(self, data):
        result = data
        for step in self.steps:
            result = step(result)
        return result

# 使用
pipeline = Pipeline()
pipeline.add_step(fetch_data)
pipeline.add_step(clean_data)
pipeline.add_step(filter_data)
pipeline.add_step(format_output)
result = pipeline.execute(input_data)
```

### 22.10.2 Strategy（策略）模式

**适用场景**：多种算法可互换

```python
class RetryStrategy:
    def retry(self, func, max_retries):
        pass

class FixedIntervalStrategy(RetryStrategy):
    def retry(self, func, max_retries, interval=10):
        for i in range(max_retries + 1):
            try:
                return func()
            except Timeout:
                if i < max_retries:
                    time.sleep(interval)
        raise

class ExponentialBackoffStrategy(RetryStrategy):
    def retry(self, func, max_retries, base_delay=1):
        for i in range(max_retries + 1):
            try:
                return func()
            except Timeout:
                if i < max_retries:
                    wait = base_delay * (2 ** i)
                    time.sleep(wait)
        raise
```

### 22.10.3 Observer（观察者）模式

**适用场景**：事件通知

```python
class EventManager:
    def __init__(self):
        self.listeners = {}
    
    def subscribe(self, event_type, listener):
        if event_type not in self.listeners:
            self.listeners[event_type] = []
        self.listeners[event_type].append(listener)
    
    def publish(self, event_type, data):
        if event_type in self.listeners:
            for listener in self.listeners[event_type]:
                listener(data)

# 使用
event_manager = EventManager()
event_manager.subscribe("task_completed", send_notification)
event_manager.subscribe("task_completed", update_dashboard)
event_manager.publish("task_completed", result)
```
