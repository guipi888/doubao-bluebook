## 21.11 理论要点：Codex 的核心概念

### 21.11.1 从 Chat 到 Workspace

**传统 Chat**：
- 输入 → 输出 → 结束
- 每次新建对话
- 上下文有限

**Codex Workspace**：
- 目标 → 分解 → 执行 → 验证
- 持久线程
- 长期记忆

### 21.11.2 核心机制

| 机制 | 说明 | 实践 |
|------|------|------|
| **Durable Threads** | 持久线程 | 重要任务使用固定线程 |
| **Memory Vault** | 外部记忆库 | 重要信息写入文件 |
| **Verification Gates** | 验证门 | 每步验证后再继续 |
| **Human-in-the-Loop** | 人工介入 | 关键节点人工确认 |

## 21.12 实战技巧

### 21.12.1 技巧1：固定重要线程

**原则**：重要任务不要每次新开对话。

**实践**：
```
适合使用固定线程的任务：
- 产品开发（多天持续）
- 客户跟进（多轮沟通）
- 内容创作（系列文章）
- 研究项目（长期调研）

固定线程内积累：
- 过往决策
- 项目背景
- 用户偏好
- 未完成事项
```

### 21.12.2 技巧2：建立 Memory Vault

**结构**：
```
vault/
├── TODO.md
├── people/
│   ├── alice.md
│   └── bob.md
├── projects/
│   ├── project-a.md
│   └── project-b.md
├── agent/
│   └── preferences.md
└── notes/
    └── decisions.md
```

**使用**：
```python
# 读取记忆
with open("vault/TODO.md") as f:
    todo = f.read()

# 写入记忆
with open("vault/decisions.md", "a") as f:
    f.write(f"\n## {date}\n{decision}\n")
```

### 21.12.3 技巧3：使用工具而非只聊天

**工具分类**：
- 本地浏览器：预览网页
- Chrome：处理登录态
- Computer Use：操作 GUI
- Connectors：连接外部服务
- Skills：复用流程

### 21.12.4 技巧4：边做边 Steering

```
传统方式：
需求 → 执行 → 检查 → 发现不对 → 重新来

Steering 方式：
需求 → 执行 → 中途补充 → 调整 → 继续执行
```
