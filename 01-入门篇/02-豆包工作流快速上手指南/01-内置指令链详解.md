# 豆包工作流入口详解：内置指令链

> **章节**：入门篇第2章第1节  
> **难度**：⭐ 入门级  
> **阅读时间**：15-20 分钟  
> **核心收获**：掌握豆包内置指令链的配置和使用方法

---

## 2.1 理论要点：什么是内置指令链

### 2.1.1 核心概念

**内置指令链**是豆包提供的最基础工作流入口，允许用户：
- 将常用的 Prompt 保存为自定义指令
- 设置触发词，一键启动多步骤流程
- 利用多轮对话记忆保持上下文

**适用场景**：
- 个人轻量任务
- 重复性操作
- 无需团队协作
- 数据源固定

### 2.1.2 指令链的组成

| 组件 | 说明 | 示例 |
|------|------|------|
| **指令名称** | 任务的简短描述 | "AI热点选题日报" |
| **触发词** | 启动指令的关键词 | "启动选题任务" |
| **Prompt** | 完整的任务描述 | 包含角色、任务、输入、输出格式 |
| **约束条件** | 执行过程中的限制 | "不编造参数"、"不超出指定时长" |
| **输出格式** | 期望的输出结构 | 清单、表格、JSON |

### 2.1.3 指令链的局限性

| 局限性 | 说明 | 解决方案 |
|--------|------|----------|
| **单次执行** | 一次只能运行一个指令 | 需要手动串接多个指令 |
| **无定时触发** | 需要手动或外部触发 | 配合 WorkBuddy 自动化 |
| **数据源有限** | 主要依赖豆包能力 | 需要外部数据源时升级到 MCP |
| **无状态管理** | 不持久化运行状态 | 配合状态文件实现断点续跑 |

## 2.2 实战案例：配置"AI热点选题日报"指令

### 2.2.1 步骤详解

**步骤1：创建指令**

1. 打开豆包，点击右上角"+"
2. 选择"创建新指令"
3. 填写指令信息：
   ```
   指令名称：AI热点选题日报
   触发词：启动选题任务
   ```

**步骤2：编写 Prompt**

```
你是AI领域的内容助手。我是AI博主，内容方向是AI教程、AI工具、AI Coding、AI测评。

请帮我找今日AI领域的热点，方便我筛选选题。

来源：
- 微信公众号近期爆款文章
- GitHub今日热门AI项目
- 多引擎AI新闻聚合
- AI热点追踪

输出格式：
1. 标题
2. 一句话摘要
3. 来源
4. 建议角度（功能测评/上手教程/观点分析）

要求：
- 只保留真正属于AI领域的内容
- 排除泛科技、数码产品、互联网公司动态
- 同一事件在不同来源出现时合并为一条
- 过滤后至少保留5条，否则标注"内容不足"
- 按热度排序，最热的放在前面
```

**步骤3：保存并测试**

1. 点击"保存"
2. 在对话框输入"启动选题任务"
3. 检查输出是否符合预期
4. 调整 Prompt 直到满意

## 2.3 高级技巧

### 2.3.1 多轮对话记忆

**场景**：第一次运行后，豆包记住你的偏好。

**实现方式**：
```
第一次：
你：启动选题任务
豆包：[输出清单]
你：工具类内容很实用，观点类内容角度太老，以后优先收录工具类

第二次：
你：启动选题任务
豆包：[自动调整权重，优先工具类]
```

**原理**：豆包自动记忆上下文，后续指令会参考之前的反馈。

### 2.3.2 指令嵌套

**场景**：一个指令调用另一个指令。

**示例**：
```
主指令：内容生产全流程
  1. 调用"AI热点选题日报"获取热点
  2. 调用"标题生成器"生成标题
  3. 调用"脚本生成器"生成脚本
```

**限制**：豆包内置指令链不支持直接嵌套，需要通过 WorkBuddy 或外部脚本实现。

## 2.5 常见错误

| 错误 | 后果 | 纠正方法 |
|------|------|----------|
| Prompt 过长 | 豆包遗漏关键要求 | 拆分为多个步骤，逐步执行 |
| 触发词太简单 | 容易误触发 | 使用特定词组，如"启动AI选题任务" |
| 输出格式不固定 | 每次结果不同 | 用严格模板约束格式 |
| 依赖单次记忆 | 上下文丢失后行为变化 | 关键偏好写入 CL AUDE.md 或配置文件 |
| 过度复杂化 | 指令链难以维护 | 保持简单，一个指令做一件事 |
