## 2.10 理论要点：全局工作流入口

### 2.10.1 核心概念

**桌面版 Alt+空格**是豆包提供的全局快捷键，允许用户在任何界面快速唤起 AI 助手。

**核心能力**：
- **全局唤起**：在任何应用中按 Alt+空格
- **意图识别**：自动判断任务类型（问答/搜索/翻译/总结）
- **跨应用操作**：读取浏览器、操作文件、截图识别

### 2.10.2 适用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **即时任务** | 突然需要处理的事情 | 看到好文章，立即保存摘要 |
| **跨应用操作** | 需要在多个应用间切换 | 浏览器 → 飞书文档 |
| **快速查询** | 临时查资料 | 选中文本，立即翻译 |
| **截图识别** | 图片信息提取 | 截图 → 提取文字/表格 |

### 2.10.3 与内置指令链的区别

| 维度 | 内置指令链 | 桌面版 Alt+空格 |
|------|-----------|----------------|
| **触发方式** | 在豆包对话框输入触发词 | 全局快捷键，任何界面 |
| **使用场景** | 固定流程的自动化任务 | 临时、即时的任务 |
| **上下文** | 豆包内部上下文 | 可读取当前应用内容 |
| **持久化** | 可保存为指令 | 不保存，一次性使用 |

## 2.11 实战案例：跨应用信息收集

### 2.11.1 场景描述

**需求**：在浏览器看到一篇好文章，快速保存链接和摘要到飞书文档。

### 2.11.2 步骤详解

**步骤1：配置桌面版**

1. 下载并安装豆包桌面版
2. 登录账号
3. 进入设置 → 快捷键
4. 确认 Alt+空格 已启用

**步骤2：授权权限**

```
必要权限：
- 浏览器访问（读取当前页面）
- 文件系统访问（保存文件）
- 截图权限（可选，用于图像识别）
```

**步骤3：使用流程**

```
1. 在浏览器打开文章
2. 按 Alt+空格 唤起豆包
3. 说："保存这篇文章的链接和摘要到飞书文档"
4. 豆包自动：
   - 读取浏览器当前页面
   - 提取标题、链接、摘要
   - 打开飞书文档
   - 写入内容
5. 确认保存完成
```

## 2.13 常见错误

| 错误 | 后果 | 纠正方法 |
|------|------|----------|
| 权限未授权 | 豆包无法访问浏览器/文件 | 提前授权并测试 |
| 快捷键冲突 | Alt+空格 被其他应用占用 | 修改快捷键或关闭冲突应用 |
| 意图识别错误 | 豆包理解错任务类型 | 用更明确的指令 |
| 跨应用操作失败 | 应用不支持读取 | 检查应用兼容性 |
| 过度依赖 | 复杂任务用桌面版效率低 | 复杂任务还是用内置指令链 |
