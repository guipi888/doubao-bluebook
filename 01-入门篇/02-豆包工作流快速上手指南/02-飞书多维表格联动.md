## 2.6 理论要点：飞书多维表格 + 豆包

### 2.6.1 核心概念

**飞书多维表格联动** = 结构化数据存储 + 自动化规则 + 豆包 AI 能力

**工作流**：
```
数据录入 → 触发条件 → 自动调用豆包 → 结果写回表格 → 通知相关人员
```

### 2.6.2 适用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **团队协作** | 多人共享数据，统一处理 | 内容团队选题池 |
| **结构化数据** | 数据有固定字段和格式 | 客户信息、订单数据 |
| **流程审批** | 需要多级审核 | 内容审核、客户跟进 |
| **数据追踪** | 需要记录历史 | 任务状态追踪、绩效统计 |

### 2.6.3 架构组成

```
┌─────────────────────────────────────────┐
│           飞书多维表格（数据中枢）           │
│  ├── 原始数据字段                         │
│  ├── 状态字段（单选）                     │
│  └── 结果字段（文本）                     │
└─────────────────────────────────────────┘
              ↓ 自动化规则触发
┌─────────────────────────────────────────┐
│           飞书机器人                      │
│  ├── 读取表格数据                         │
│  ├── 拼接 Prompt                          │
│  └── 调用豆包 API                         │
└─────────────────────────────────────────┘
              ↓ 结果回写
┌─────────────────────────────────────────┐
│           更新多维表格                     │
│  └── 结果字段 + 状态字段更新               │
└─────────────────────────────────────────┘
              ↓ 通知
┌─────────────────────────────────────────┐
│           飞书群消息 / 邮件                │
└─────────────────────────────────────────┘
```

## 2.7 实战案例：团队内容审核工作流

### 2.7.1 场景描述

**团队**：内容团队 5 人（1 主编 + 4 内容创作者）  
**需求**：每日热点自动聚合，主编审核后推送到对应频道

### 2.7.2 步骤详解

**步骤1：创建飞书多维表格**

```
表格名称：团队热点选题池

字段定义：
├── 日期（日期）- 格式：YYYY-MM-DD
├── 类别（单选）- AI工具 / AI Coding / 行业动态 / 深度观察
├── 标题（文本）- 热点标题
├── 摘要（文本）- 一句话摘要
├── 来源（文本）- 数据来源
├── 原始链接（URL）- 原文链接
├── 状态（单选）- 待审核 / 已通过 / 已驳回 / 已推送
├── 审核人（人员）- 主编
├── 审核意见（文本）- 驳回原因或修改建议
├── 推送时间（日期时间）- 实际推送时间
└── 推送结果（单选）- 成功 / 失败
```

**步骤2：配置自动化规则**

**规则1：自动聚合**
```
触发条件：每天 09:00（定时）
执行动作：
1. 调用豆包 API，传入 Prompt
2. 获取热点清单
3. 按类别写入表格（状态：待审核）
```

**规则2：审核通过后推送**
```
触发条件：【状态】更新为"已通过"
执行动作：
1. 提取该行所有字段
2. 拼接为推送消息格式
3. 推送到对应频道
4. 更新【推送时间】和【推送结果】
```

**规则3：审核驳回通知**
```
触发条件：【状态】更新为"已驳回"
执行动作：
1. 发送飞书消息给该行【创建人】
2. 消息包含【审核意见】
```

**步骤3：配置豆包 Prompt**

```
你是内容团队的选题助手。请帮我聚合今日AI领域热点。

来源：
- 微信公众号近期爆款文章
- GitHub今日热门AI项目
- 多引擎AI新闻聚合
- AI热点追踪

输出格式（JSON数组）：
[
  {
    "category": "AI工具",
    "title": "标题",
    "summary": "一句话摘要",
    "source": "来源",
    "url": "原文链接",
    "suggested_angle": "建议角度"
  }
]

要求：
- 只保留真正属于AI领域的内容
- 按类别分类
- 至少保留5条，否则标注"内容不足"
```

**步骤4：权限配置**

```
权限设置：
- 内容创作者：可查看、可编辑（自己的行）
- 主编：可查看、可编辑、可审核（所有行）
- 豆包机器人：可读取、可写入（通过 API）
```

## 2.9 常见错误

| 错误 | 后果 | 纠正方法 |
|------|------|----------|
| 字段设计不合理 | 后续无法满足需求 | 提前规划，参考成熟模板 |
| 自动化规则过于复杂 | 难以维护和调试 | 拆分为多个简单规则 |
| 权限配置不当 | 数据泄露或无法操作 | 遵循最小权限原则 |
| Prompt 输出格式不固定 | 表格写入失败 | 用 JSON 等结构化格式约束 |
| 忽略错误处理 | 规则失败后无提示 | 配置失败告警 |
