# 豆包工作流入口详解：选择决策树

> **章节**：入门篇第2章第5节  
> **难度**：⭐ 入门级  
> **阅读时间**：10-15 分钟  
> **核心收获**：学会根据场景选择最合适的工作流入口

---

## 2.18 理论要点：没有最好的，只有最合适的

### 2.18.1 选择工作流入口的决策因素

| 因素 | 说明 | 权重 |
|------|------|------|
| **是否需要团队协作** | 多人使用 vs 个人使用 | 高 |
| **数据源复杂度** | 是否需要外部数据源 | 高 |
| **任务复杂度** | 单步 vs 多步 | 中 |
| **实时性要求** | 即时响应 vs 批量处理 | 中 |
| **成本预算** | 免费 vs 付费 | 低 |

### 2.18.2 四种入口的适用边界

```
                    需要团队协作？
                   /            \
                 是              否
                /                  \
          飞书多维表格          需要外部数据源？
          + 豆包                /         \
                               是           否
                              /               \
                       WorkBuddy/MCP      内置指令链
                      + 豆包
```

### 2.18.3 快速选择表

| 场景 | 推荐入口 | 原因 |
|------|----------|------|
| 个人每日任务 | 内置指令链 + WorkBuddy | 简单、高效、低成本 |
| 团队协作 | 飞书多维表格 + 豆包 | 结构化、可追踪 |
| 即时操作 | 桌面版 Alt+空格 | 全局唤起、跨应用 |
| 复杂多步任务 | WorkBuddy/MCP + 豆包 | 灵活、可编排 |

## 2.19 实战案例：不同场景的选择

### 2.19.1 场景对比

| 场景 | 入口选择 | 理由 |
|------|----------|------|
| **个人每日热点选题** | 内置指令链 + WorkBuddy | 个人使用，数据源固定，定时执行 |
| **团队内容审核** | 飞书多维表格 + 豆包 | 需要多级审核，结构化追踪 |
| **跨应用信息收集** | 桌面版 Alt+空格 | 即时操作，跨应用 |
| **市场分析报告** | WorkBuddy/MCP + 豆包 | 多数据源，复杂生成 |

### 2.19.2 迁移路径

```
L1：内置指令链（个人轻量）
    ↓ 需要外部数据源
L2：WorkBuddy/MCP + 豆包（个人进阶）
    ↓ 需要团队协作
L3：飞书多维表格 + 豆包（团队使用）
    ↓ 需要复杂编排
L4：Workflow as Code（专家级）
```

## 2.21 常见错误

| 错误 | 后果 | 纠正方法 |
|------|------|----------|
| 过度复杂化 | 简单任务用复杂工具 | 从简单开始，按需升级 |
| 入口混用 | 同一任务用多个入口 | 明确主入口，避免混淆 |
| 忽视成本 | 用高成本方案解决简单问题 | 评估成本效益 |
| 过早优化 | 还没跑通就考虑扩展 | 先跑通 L1，再考虑 L2+ |
| 忽略团队需求 | 个人工具直接丢给团队 | 评估团队协作需求 |
