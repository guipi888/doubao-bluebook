## 2.14 理论要点：四大智能体

### 2.14.1 核心概念

豆包的四大智能体模块是工作流的核心执行单元：

| 模块 | 核心能力 | 适用场景 |
|------|----------|----------|
| **对话智能体** | 多轮上下文理解、意图识别 | 问答、澄清需求、复杂对话 |
| **检索智能体** | 实时联网搜索、信息整合 | 资料收集、事实核查 |
| **创作智能体** | 写作润色、图片理解、智能修图 | 内容生成、文案改写 |
| **办公智能体** | 文档处理、多语翻译、日程辅助 | 报告生成、文档转换 |

### 2.14.2 模块组合模式

**模式1：单模块**
```
对话智能体 → 直接问答
```

**模式2：串行组合**
```
检索智能体 → 收集资料
    ↓
创作智能体 → 生成报告
    ↓
办公智能体 → 导出为文档
```

**模式3：并行组合**
```
检索智能体 → 收集资料A
    ↓
对话智能体 → 收集资料B（并行）
    ↓
创作智能体 → 整合生成（等待两者完成）
```

### 2.14.3 能力边界

| 能力 | 支持 | 不支持 |
|------|------|--------|
| 多轮对话 | ✅ | - |
| 联网搜索 | ✅ | 深度学术检索 |
| 代码生成 | ✅ | 复杂项目开发 |
| 图像理解 | ✅ | 高精度 OCR |
| 文件处理 | ✅ | 大文件（>100页） |
| 浏览器控制 | ✅ | 复杂交互操作 |

## 2.15 实战案例：多模块组合工作流

### 2.15.1 场景：生成市场分析报告

**需求**：基于最新信息，生成一份市场分析报告。

**工作流设计**：
```
1. 检索智能体：收集行业最新动态
2. 对话智能体：澄清分析角度和重点
3. 创作智能体：生成报告初稿
4. 办公智能体：导出为 Word/PDF
```

**Prompt 设计**：
```
# 阶段1：检索
请搜索2026年Q2中国AI编程助手市场的最新动态，
包括：产品发布、融资收购、用户增长、技术趋势。

# 阶段2：对话
基于搜索结果，请确认以下问题：
1. 分析重点是ToC还是ToB？
2. 需要包含哪些竞品对比？
3. 报告长度要求？

# 阶段3：创作
基于确认的角度，生成一份markdown格式的市场分析报告，
包含：概述、市场格局、趋势分析、建议。

# 阶段4：办公
将markdown转换为Word文档，添加目录和页眉页脚。
```

## 2.17 常见错误

| 错误 | 后果 | 纠正方法 |
|------|------|----------|
| 单模块承担过多 | 质量下降 | 拆分为多模块串行 |
| 模块组合不当 | 效率低下 | 评估是否真的需要多模块 |
| 忽略模块限制 | 任务失败 | 了解每个模块的能力边界 |
| 上下文丢失 | 多模块间信息不一致 | 明确传递必要上下文 |
| 过度复杂化 | 难以维护 | 从单模块开始，逐步扩展 |
