# 豆包工作流快速上手指南

> **章节**：入门篇第2章  
> **难度**：⭐ 入门级  
> **阅读时间**：15-20 分钟  
> **核心收获**：掌握豆包四种工作流入口的使用方法，快速搭建第一个自动化任务

---

## 2.1 理论要点：豆包工作流的本质

### 2.1.1 从"对话"到"工作流"的思维转变

**传统用法**（❌ 低效）：
```
你：帮我找今天的AI热点
豆包：[返回结果]
你：帮我整理成清单
豆包：[返回清单]
你：帮我推送到飞书
...
```

**工作流思维**（✅ 高效）：
```
定义一次 → 自动执行 → 持续运行
```

**核心公式**：
```
工作流 = 触发条件 + 执行逻辑 + 输出格式 + 推送目标
```

### 2.1.2 豆包的四种工作流入口

| 入口 | 技术实现 | 最佳场景 | 学习曲线 |
|------|----------|----------|----------|
| **内置指令链** | 自定义指令 + 多轮对话记忆 | 个人轻量任务 | 平缓 |
| **飞书多维表格联动** | 表格字段 + 自动化规则 | 团队协作、结构化数据 | 中等 |
| **桌面版 Alt+空格** | 全局快捷键 + 意图识别 | 即时任务、跨应用操作 | 平缓 |
| **四大智能体模块** | 对话/检索/创作/办公组合 | 复杂多步任务 | 较陡 |

## 2.2 实战案例：三种场景的工作流搭建

### 2.2.1 场景1：个人每日热点选题（内置指令链）

**适用**：个人使用，数据源固定，输出格式简单

**步骤详解**：

1. **创建自定义指令**
   - 进入豆包 → 右上角"+" → 创建新指令
   - 指令名称：`AI热点选题日报`
   - 触发词：`启动选题任务`
   - Prompt：见下文

2. **设置定时任务**
   - WorkBuddy → 自动化 → 新建任务
   - Prompt：`启动选题任务`
   - 定时：每天 09:00
   - 推送：个人飞书通知

3. **Prompt 模板**
   ```
   我是AI领域博主...
   [完整Prompt见第1章案例]
   ```

### 2.2.2 场景2：团队内容审核（飞书多维表格联动）

**适用**：团队协作，需要多级审核，结构化数据追踪

**架构设计**：
```
数据源 → 豆包聚合 → 飞书多维表格 → 主编审核 → 自动推送
```

**实现步骤**：

1. **创建飞书多维表格**
   ```
   表格名称：团队热点选题池
   字段：
   - 日期（日期）
   - 类别（单选：AI工具/AI Coding/行业动态）
   - 标题（文本）
   - 摘要（文本）
   - 来源（文本）
   - 状态（单选：待审核/已通过/已驳回/已推送）
   - 审核人（人员）
   - 推送时间（日期时间）
   ```

2. **配置自动化规则**
   ```
   触发条件：当【状态】更新为"已通过"
   执行动作：
   1. 提取该行所有字段
   2. 拼接为推送消息格式
   3. 推送到对应频道
   4. 更新【推送时间】为当前时间
   ```

3. **豆包角色**：仅负责数据聚合和过滤，不做最终推送

### 2.2.3 场景3：跨应用操作（桌面版 Alt+空格）

**适用**：需要在多个应用间切换，即时处理任务

**使用场景示例**：
```
1. 在浏览器看到一篇好文章
2. 按 Alt+空格 唤起豆包
3. 说"保存这篇文章的链接和摘要"
4. 豆包自动读取浏览器当前页面
5. 提取内容并保存到飞书文档
```

**关键配置**：
- 开启"系统级划词与截图辅助"
- 授权豆包访问浏览器和文件系统
- 设置常用意图（保存/总结/翻译/提取）

## 2.3 操作模板：第一次工作流检查清单

### 2.3.1 任务定义模板

```
任务名称：[简短描述，如"AI热点选题日报"]
触发方式：[定时/手动/事件驱动]
触发时间：[如每天 09:00]
触发条件：[如"飞书多维表格有待处理行"]

Prompt：[完整 Prompt 文本]

数据源：[列出所有数据源]
数据源检查：[每个来源的探活方法]

质量门禁：[有效条目 ≥ X 条；数据源可用数量 ≥ Y 个]

输出格式：[结构化格式说明]

推送目标：[飞书群/个人通知/文档追加/邮件]

幂等控制：批次 ID = {task-name}-{date}

重试策略：[数据源超时重试 X 次；推送失败退避重试 Y 次]

告警接收：[个人飞书通知/邮件]

owner：[负责人]

停用方式：[具体操作路径]
```

### 2.3.2 豆包指令链模板

```
指令名称：[如"短视频全流程生成"]
触发词：[如"启动短视频流程"]

流程：
  1. 询问目标受众与核心产品
  2. 生成 3 个热点相关选题
  3. 用户选定后，输出分镜头脚本（含画面描述、台词、BGM 建议）
  4. 生成 5 个高点击率标题及简介

约束：
- 不改变产品结构
- 不编造参数
- 不超出用户指定的时长
```

### 2.3.3 飞书多维表格联动模板

```
表格字段：
- 【原始文案】（文本）
- 【改写类型】（单选：口语化/精简版/SEO优化）
- 【预期字数】（数字）
- 【状态】（单选：待处理/处理中/已完成）
- 【改写结果】（文本）

自动化规则：
当【状态】更新为"待处理"时：
  1. 提取【原始文案】与【改写类型】
  2. 拼接为标准 prompt
  3. 调用豆包 AI 接口
  4. 结果填入【改写结果】
  5. 状态更新为"已完成"
```

## 2.5 常见错误

| 错误 | 后果 | 纠正方法 |
|------|------|----------|
| Prompt 太长太复杂 | 豆包容易遗漏关键要求 | 拆分为多个步骤，逐步执行 |
| 定时任务与手动触发冲突 | 重复执行 | 设置幂等控制，检测批次 ID |
| 过度依赖内置指令链 | 复杂任务无法满足 | 评估是否需要升级到飞书表格或 MCP |
| 忽略权限配置 | 豆包无法访问文件/浏览器 | 提前授权，测试权限边界 |
