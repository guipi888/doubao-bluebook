## 19.10 理论要点：工具化迁移

### 19.10.1 迁移工具分类

| 工具类型 | 说明 | 示例 |
|----------|------|------|
| **评估工具** | 评估当前状态 | 问卷、打分表 |
| **规划工具** | 制定迁移计划 | 甘特图、看板 |
| **执行工具** | 辅助迁移实施 | 脚本、模板 |
| **验证工具** | 验证迁移效果 | 测试框架、监控 |
| **回滚工具** | 快速回滚 | 版本控制、备份 |

### 19.10.2 检查清单的作用

**检查清单的价值**：
- 确保不遗漏关键步骤
- 统一团队操作规范
- 便于培训和复用
- 支持审计和追溯

```markdown
- [ ] 记录运行日志

- 0-4：建议从入门篇开始

```

## 19.13 常见错误

| 错误 | 后果 | 纠正方法 |
|------|------|----------|
| 无评估直接迁移 | 目标不明确 | 使用评估问卷 |
| 无检查清单 | 遗漏关键步骤 | 按检查清单执行 |
| 一次性全做 | 风险集中 | 分阶段验证 |
| 无回滚方案 | 出问题无法恢复 | 提前准备回滚 |
| 不记录进度 | 难以追踪 | 使用项目管理工具 |
